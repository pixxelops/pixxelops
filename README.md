## 🚀 Featured Project

### 🛍️ NovaCart — Full-Stack E-Commerce Platform

A full-stack e-commerce application built using React, TypeScript, Spring Boot and MySQL.

**Key features:**

- JWT authentication and role-based access control.
- Product discovery, search and pagination.
- Shopping cart and order management.
- Razorpay checkout with server-side payment signature verification.
- Inventory updates after successful payment verification.
- Cloudinary-based product image storage.
- Production deployment using Vercel, Render and Aiven.
